# Graphify Output — Knowledge Graph

Auto-generated code knowledge graph. Updated by running `graphify update .` after code changes.

## Files

- `graph.json` — full graph data (nodes + edges)
- `graph.html` — interactive visualization
- `GRAPH_REPORT.md` — summary report with community structure
- `wiki/index.md` — broad codebase navigation
- `cache/` — AST parse cache

## Regenerate

```bash
graphify update .
```
